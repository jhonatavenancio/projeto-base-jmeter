# 🔧 Projeto Modelo de Teste de Estresse com JMeter

Este repositório contém um projeto modelo utilizando o **Apache JMeter** para realizar testes de estresse em uma API. O objetivo é fornecer uma estrutura base reutilizável para execução de testes de performance simples, com configuração via variáveis como `URL` e `TOKEN`.

## 🧪 Objetivo

Demonstrar como estruturar um projeto básico de testes de estresse com JMeter, utilizando variáveis parametrizadas para facilitar a reutilização em diferentes ambientes.
